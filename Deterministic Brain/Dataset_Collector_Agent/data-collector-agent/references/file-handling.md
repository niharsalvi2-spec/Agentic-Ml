# File Handling

Reading data that already exists as CSV, JSON, Excel, or PDF.

## CSV

```python
import pandas as pd

df = pd.read_csv("data.csv")
df = pd.read_csv("data.csv", encoding="utf-8")
df = pd.read_csv("data.csv", sep=";")            # semicolon separated
df = pd.read_csv("data.csv", skiprows=2)          # skip header rows
df = pd.read_csv("data.csv", nrows=1000)          # read only first 1000 rows
df = pd.read_csv("data.csv", usecols=["a", "b"])  # specific columns

df.to_csv("output.csv", index=False)
```

## JSON

```python
import pandas as pd, json

df = pd.read_json("data.json")  # flat JSON

# Nested JSON needs normalization
with open("nested.json") as f:
    data = json.load(f)

df = pd.json_normalize(
    data,
    record_path=["orders"],       # nested list to expand
    meta=["customer_id", "name"], # parent fields to keep
)
```

## Excel

```python
import pandas as pd

df = pd.read_excel("data.xlsx", sheet_name="Sheet1")
all_sheets = pd.read_excel("data.xlsx", sheet_name=None)  # dict: {'Sheet1': df1, ...}

df.to_excel("output.xlsx", sheet_name="Results", index=False)
```

For substantial spreadsheet creation/formatting work (not just reading raw data), use the `xlsx` skill instead of ad hoc pandas writes.

## PDF (text and tables)

```python
import pdfplumber
import pandas as pd

with pdfplumber.open("report.pdf") as pdf:
    for page in pdf.pages:
        print(page.extract_text())

with pdfplumber.open("report.pdf") as pdf:
    table = pdf.pages[0].extract_table()
    df = pd.DataFrame(table[1:], columns=table[0])
```

For heavier PDF work (forms, OCR, merging/splitting), use the `pdf` / `pdf-reading` skills instead of building this from scratch.

## Notes

- Always check `df.dtypes` and `df.shape` right after loading — silent type coercion (e.g. an ID column becoming float) is the most common file-ingestion bug.
- For files delivered by the user directly (not generated by this collector), see the `file-reading` skill first.
